# ADR 0004 — Jaringan Bahasa lunak

Status: Diterima

## Konteks
Bahasa sebagai antarmuka bentuk-makna, bukan tempat berpikir; kapasitas khusus tapi ada jalur bersama.

## Keputusan
Jaringan Bahasa (L12) terpisah dari korteks (L1) dan MFM (L2), dengan jatah kapasitas yang diuji via ablasi.

## Konsekuensi
- Lesion test wajib (G7).
- Jatah kapasitas adalah tebakan awal, ditetapkan lewat ablasi.
